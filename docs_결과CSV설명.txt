min_area 필터를 통과한 입자만 기록됩니다.

│ ecd_um           │ μm     │ 등가원직경 (Equivalent Circle Diameter)           │

│                  │        │  입자와 면적이 동일한 원의 지름.                  │
│                  │        │  SDAS 측정 시 Alpha-Al의 ECD를 사용하면          │
│                  │        │  수지상 셀 크기의 근사값으로 활용 가능.           │
├──────────────────┼────────┼───────────────────────────────────────────────────┤
│ circularity      │ —      │ 원형도 (0~1)                                      │
│                  │        │  = 4π × 면적 / 둘레²                             │
│                  │        │  1 = 완전한 원 / 0에 가까울수록 가늘고 길쭉함    │

│                  │        │  1 = 정사각형(원) / 클수록 길쭉함                │

================================================================================
  ECD (등가원직경) 해석 참고
================================================================================

ECD는 입자의 2차원 단면 크기를 원 지름으로 환산한 값입니다.

  · Si: Si 입자의 크기 분포를 나타냄.
        작은 ECD + 높은 원형도 → 잘 구상화된(modified) Si
        큰 ECD + 낮은 원형도 → 침상형 공정 Si (미개량)

  · IM: β-Fe(Al5FeSi, 침상), α-Fe(Al15(FeMn)3Si2, 중국 문자형) 등을 포함.
        ECD와 종횡비로 침상(high AR) vs. 괴상(low AR) 구분 가능.

  · 기공: 기공의 크기 및 개수로 주조 결함 정도를 평가.

  · Alpha-Al: Watershed로 수지상 셀을 분리한 뒤 ECD를 측정하면
              SDAS(Secondary Dendrite Arm Spacing)의 근사값으로 활용 가능.
              단, 2D 단면 측정이므로 실제 3D SDAS와 차이가 있음.
              동일 조건에서 촬영한 이미지 간 상대 비교에 적합.


================================================================================
  면적 분율(%) 해석 참고
================================================================================

  · 면적 분율은 2D 단면 기준이며, 등방성 조직 가정 시 체적 분율과 근사합니다.
  · Alpha-Al 분율은 Watershed 소파편 포함 전체 Al 픽셀 기준입니다.
    (ECD 통계는 min_area + 최소 씨앗 거리 필터 통과 입자만 포함)
  · 스케일 바 영역은 분석에서 자동 제외되므로 분율 계산의 분모(총 픽셀 수)에
    포함되지 않습니다.


================================================================================
  스케일 팩터
================================================================================

  기본값: 0.14 μm/pixel (Axioskop 2 Mat + Axiocam 820, 20× 대물렌즈 기준)
