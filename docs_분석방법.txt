■ 분석 대상 상(Phase)
--------------------------------------------------------------------------------
  이 프로그램은 ADC12 알루미늄 합금 주조재의 광학현미경(OM) 이미지에서
  아래 4가지 상을 구분합니다.

    1. 기공 (Pore)
    2. 공정 Si (Eutectic Si)
    3. 금속간화합물 (Intermetallic Compound, IM)
    4. 알파-알루미늄 매트릭스 (Alpha-Al)

  에칭 후 관찰 기준 밝기 순서: 기공(가장 어두움) < Si < IM < Alpha-Al(가장 밝음)


================================================================================
  STEP 1. 전처리 (Preprocessing)
================================================================================

  [1-1] Median Blur (잔점·노이즈 제거)
  ─────────────────────────────────────
  분석 전 메디안 블러(홀수 커널)를 적용하여 이미지의 먼지, 스크래치, 작은
  노이즈를 제거합니다.
  - 커널이 클수록 더 강하게 제거되지만 미세 구조 경계도 뭉개질 수 있습니다.
  - GUI: "전처리 블러 (Median)" 스핀박스

  [1-2] CLAHE (조명/에칭 차이 보정)
  ─────────────────────────────────────
  CLAHE(Contrast Limited Adaptive Histogram Equalization)는 이미지를 작은
  타일(기본 8×8)로 나눠 각 타일 안에서 히스토그램을 평탄화합니다.
  - 목적: 사진마다 다른 조명 세기·에칭 깊이 차이를 보정하여 임계값 적용의
          일관성을 높임
  - clip_limit(기본 1.0): 낮을수록 보정량이 적음. 너무 높으면 노이즈 증폭
  - GUI: "CLAHE 정규화 사용" 체크박스

  ※ 주의: CLAHE는 타일 단위 로컬 보정이므로, Si/IM이 많아 어두운 타일에서는
          Si 픽셀의 밝기값이 인위적으로 낮아질 수 있습니다.
          이 때문에 기공 감지는 CLAHE 적용 전(블러만 적용) 이미지를 사용하며,
          Si/IM/Alpha-Al 감지는 CLAHE 적용 후 이미지를 사용합니다.

  [1-3] 스케일 바 자동 감지 및 제외
  ─────────────────────────────────────
  이미지 하단의 흰색 스케일 바 박스를 자동으로 탐지하여 분석에서 제외합니다.


================================================================================
  STEP 2. 초기 상 분류
================================================================================

  아래 두 방식 중 하나를 선택할 수 있습니다.

  ─────────────────────────────────────
  [방식 A] 수동 임계값 분류 (기본)
  ─────────────────────────────────────
  픽셀의 밝기값(gray 0~255)을 기준으로 각 상의 범위를 직접 지정합니다.

    기공       : 0  ~ pore_upper
    Eutectic Si: si_lower ~ si_upper      ← 로컬 대비 필터 추가 적용
    IM         : im_lower ~ im_upper
    Alpha-Al   : alpha_lower ~ 255

  분류 우선순위: 기공이 먼저 확정되고, 나머지 픽셀에서 Si/IM/Al 분류.

  ─────────────────────────────────────
  [방식 B] GMM 자동 분류 (선택)
  ─────────────────────────────────────
  기공과 Alpha-Al은 수동 임계값을 유지하고,
  그 사이의 중간 구간 픽셀(Si + IM 후보)에 대해
  2-component Gaussian Mixture Model(GMM)을 적용하여
  Si / IM 경계를 이미지마다 자동으로 찾습니다.

  - 어두운 성분 → Si,  밝은 성분 → IM
  - 이미지 간 에칭/조명 차이가 있어도 Si/IM 경계가 자동 적응
  - 분석 후 콘솔에 GMM이 찾은 평균 밝기값이 출력됩니다.
  - GUI: "GMM 자동 분류" 체크박스 (체크 시 Si/IM 범위 스핀박스 비활성화)


================================================================================
  STEP 3. 로컬 대비 필터 (Si/IM 오탐 방지)
================================================================================

  Alpha-Al 수지상 내부는 Si/IM과 밝기가 비슷한 영역이 존재할 수 있습니다.
  로컬 대비 필터는 "주변 평균보다 min_diff 이상 어두운 픽셀만 Si 후보로 인정"하는
  조건을 적용하여 Al 덴드라이트 내부의 오탐을 줄입니다.

    - 커널 크기: 주변 평균을 구할 영역 (클수록 넓은 범위와 비교)
    - 최소 차이: 이 값보다 주변과 밝기 차이가 작으면 Si 후보에서 제외 → Alpha-Al로 재분류
    - GUI: "로컬 대비 (Si/IM)" 섹션 (0=끔)


================================================================================
  STEP 4. 경계 그래디언트 오분류 방지
================================================================================

  Si와 Alpha-Al, IM과 Alpha-Al이 맞닿는 경계에는 에칭 후 그레이스케일
  그래디언트가 발생하여 경계 픽셀이 IM 밝기 범위에 걸려 IM으로 오분류됩니다.
  이를 방지하기 위해 두 가지 경계 제외 반경을 적용합니다.

    - Si 경계 제외 반경: 최종 Si 마스크를 n px 팽창 → 근접 IM 후보 픽셀을 Al로 재분류
    - Al 경계 제외 반경: Alpha-Al 마스크를 n px 팽창 → 근접 IM 후보 픽셀을 Al로 재분류
    - GUI: "경계 제외: Si [n] px  Al [n] px" 섹션 (0=끔)


================================================================================
  STEP 5. 입자 분리 (Particle Separation)
================================================================================

  각 상별로 서로 붙어있는 입자를 개별 입자로 분리하는 후처리입니다.
  상별로 독립적으로 ON/OFF 가능합니다.

  ─────────────────────────────────────
  [5-A] Watershed 분리
  ─────────────────────────────────────
  거리 변환(Distance Transform) + Watershed 알고리즘 사용.

    원리:
      1. 마스크 내 각 픽셀에서 가장 가까운 배경(0)까지의 거리를 계산
      2. 거리 값이 큰 픽셀 = 입자 중심 → 씨앗(seed) 마커로 지정
      3. 각 씨앗에서 출발하여 경계(안장점)에서 만나는 지점을 분리선으로 결정

    파라미터:
      - 민감도(dist_ratio, 0.01~0.9): 전체 최댓값의 몇 배 이상이어야 씨앗으로
        인정할지. 낮을수록 씨앗이 많아져 더 잘게 나눔. 높을수록 덜 나눔.

  ─────────────────────────────────────
  [Alpha-Al 전용 Watershed 설정]
  ─────────────────────────────────────
    씨앗 스무딩(smooth_sigma):
      씨앗 탐색 전 거리 변환 맵을 가우시안으로 블러링합니다.
      가까이 붙은 봉우리들이 하나로 합쳐지면서 씨앗 수가 줄어
      과분할(너무 잘게 나뉘는 현상)을 방지합니다.
      클수록 큰 덩어리 단위로만 분리됩니다.

    최소 씨앗 거리(min_seed_dist):
      거리 변환값이 이 값 미만인 얇은 영역은 씨앗을 받지 못하여
      이웃한 더 큰 Al 영역으로 흡수됩니다.
      씨앗 스무딩으로 해결되지 않는 얇은 파편 제거에 사용합니다.

  ─────────────────────────────────────
  [5-B] 침식(Erosion) 기반 분리
  ─────────────────────────────────────
  좁은 연결부(neck)만 끊어 입자를 분리하는 방법.

    원리:
      1. 마스크를 radius px 침식 → 연결부가 끊어짐
      2. 끊어진 덩어리를 씨앗으로 사용
      3. Watershed로 원래 크기까지 복원 → 씨앗 사이에 분리선 생성

    파라미터:
      - 목 반경: radius×2 px 미만인 연결부만 끊음
      - 길쭉한 일체 입자는 연결부가 두꺼우면 끊어지지 않음
        (Watershed와의 차이: Watershed는 길쭉한 입자도 중간에서 잘릴 수 있음)


================================================================================
  STEP 6. 면적·최소 크기 필터
================================================================================

    최소 면적 (min_area, px):
      이 픽셀 수 미만인 입자는 분석에서 제외됩니다.
      노이즈성 잔점을 제거하는 데 사용합니다.

    IM 최대 면적 (max_area, px):
      이 픽셀 수를 초과하는 IM은 Al 덴드라이트 내부로 판단하여
      Alpha-Al로 재분류합니다. (0=끔)


================================================================================
  STEP 7. 결과 출력
================================================================================

  - 결과 이미지: 원본 이미지에 색상 오버레이 (50% 투명도)
      빨강 = Alpha-Al / 초록 = Eutectic Si / 노랑 = IM / 파랑(BGR) = 기공
      흰색 선 = Watershed/침식 분리 경계

  - 면적 분율(%): 각 상이 이미지 전체 픽셀에서 차지하는 비율
      Alpha-Al 분율 = 전체 Al 픽셀 수 / 총 픽셀 수 × 100
      (min_area 필터로 제외된 작은 파편도 분율에는 포함)

  - 입자 통계: 각 상의 개별 입자에 대해 아래 특성을 계산
      · 면적 (px, μm²)
      · ECD (등가원직경, μm): 같은 면적을 갖는 원의 지름
      · 원형도 (Circularity): 4π×면적/둘레² (1=완전한 원)
      · 종횡비 (Aspect Ratio): 최소 외접 사각형의 장축/단축

  - 저장 파일: summary_analysis.csv (이미지별 1행 요약)
               *_particles.csv   (입자 1개당 1행 상세)
               analysis_results.db (SQLite DB)

  스케일 팩터
================================================================================
